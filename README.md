# Ponto de Professores — UEPB (Releases)

Instaladores do **Ponto de Professores**, app desktop (Windows) pra gerar a Folha de Presença
Individual dos professores do curso de História da UEPB.

Este repositório tem só os instaladores — sem código-fonte, sem dados de professores. O instalador
não vem com nenhum dado pré-carregado; o cadastro é feito dentro do app (manual ou importando o
horário do semestre em .docx).

Baixe a versão mais recente na aba [Releases](../../releases).
